# Blender Model Practice

A small collection of 3D modeling artifacts created while practicing Blender.

## Files

- `untitled.blend` — Blender project
- `cuchara.obj` — exported 3D mesh
- `cuchara.mtl` — material description

Open the Blender project with Blender or import the OBJ mesh into a compatible 3D tool.

This repository contains design assets, not a software application.
